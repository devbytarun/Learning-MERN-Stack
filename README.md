# Learning MERN Stack

This repository is a hands-on learning space for building full-stack applications with the MERN stack:

- MongoDB
- Express
- React
- Node.js

It contains small projects, practice exercises, and beginner-friendly examples covering both frontend and backend development.

## Repository structure

- `Node-Basics` — foundational Node.js concepts and examples
- `Node_Practice` — practical Node.js exercises
- `Express_Basics` — Express app setup and core server concepts
- `Express_Practice` — Express practice projects and routes
- `MongoDB_Basics` — MongoDB connection, models, and CRUD basics
- `Auth_Basics` — authentication concepts including JWT, password hashing, and security middleware
- `React_Basics` — React fundamentals and component concepts
- `React Basic Project` — a simple React project structure used for learning
- `src/` — the current root React + Vite app in this repository

## Root project

The root of this repository is a Vite + React application. It serves as a frontend playground while the backend learning modules live in the individual folders.

### Run the frontend

```bash
npm install
npm run dev
```

### Build for production

```bash
npm run build
```

## Learning flow

This repo is organized to follow a practical learning path:

1. Learn JavaScript and Node.js basics
2. Build APIs with Express
3. Connect to MongoDB and work with data
4. Add authentication and security best practices
5. Build frontend interfaces with React
6. Integrate frontend and backend into a full MERN app

## Notes

- Some folders are standalone projects with their own `package.json` files and can be run independently.
- The root app is a React frontend setup, while backend examples are separated by topic.
- This repo is intended for learning and experimentation rather than a single production application.

## Suggested next steps

- Start with the Node and Express basics folders
- Move into MongoDB and authentication examples
- Practice building UI components in the React folders
- Combine the learned pieces into a complete full-stack project
